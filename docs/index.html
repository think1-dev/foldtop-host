Your Linux workstation, on your iPhone

Foldtop shows your workstation's screen on your iPhone and puts a keyboard and trackpad underneath. Stand an iPhone Duo half-folded and it works like a small laptop: picture above the fold, keys below.

Foldtop has two parts: the Foldtop app on the iPhone, and a small free companion that runs on the workstation. The app connects straight to your own workstation. There is no account and no server in between.

What you need

  • An iPhone on iOS 27.1 or later with the Foldtop app. Any iPhone works; the laptop layout uses the fold on an iPhone Duo.
  • A Linux workstation running an X11 session. Wayland is not supported. In a terminal, echo $XDG_SESSION_TYPE should print x11.
  • The iPhone and the workstation on the same network, or joined by a VPN such as Tailscale.

The companion is developed and tested on Ubuntu 24.04 LTS. Other distributions with Python 3.10+, GStreamer 1.22+ and PipeWire or PulseAudio should work but have not been tried.

Set up a workstation

  1. Install what the companion needs. 
    sudo apt install git python3-gi gir1.2-gstreamer-1.0 python3-cryptography \
    gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-plugins-ugly
  2. Download and install the companion. 
    git clone https://github.com/think1-dev/foldtop-host.git
cd foldtop-host
./install.sh --apply
systemctl --user enable --now foldtop-host

    Nothing runs as root. The companion now starts whenever you log in to your desktop. If the installer reports a problem, it says what is missing.

  3. Show a pairing code. 
    foldtop-host pair

    A QR code and an 8-character code appear. Both work once, for five minutes. If the command is not found, log out and in again, or run ~/.local/bin/foldtop-host pair.

  4. Pair in the app.

    Open Foldtop, tap Pair a Workstation… and scan the QR code. Or pick your workstation under On This Network and type the code. Allow local network access when iOS asks.

  5. Connect.

    Tap the workstation in the list. Its screen appears, with the keyboard and trackpad below it.

Firewall. The iPhone reaches the workstation on TCP port 47800. If the workstation's firewall is on, allow it for your network, for example sudo ufw allow from 192.168.0.0/24 to any port 47800 proto tcp.

Using it

  • Laptop layout. On an iPhone Duo, fold it part-way and stand it up. The picture moves above the fold and the keyboard and trackpad fill the half below. Open it flat for a full-screen picture.
  • Trackpad. Move with one finger and tap to click. Tap with two fingers for a right click, three for a middle click. Slide two fingers to scroll. To drag, tap and then drag, or hold still and then move.
  • Keyboard. A full laptop layout. Tap shift, ctrl, alt or super once for the next key, twice to lock it. fn switches to function keys and common shortcuts. A hardware keyboard attached to the iPhone types straight through.
  • Sound and microphone. The workstation's sound plays on the iPhone. Switch Microphone on in the session menu (⋯) to use the iPhone as the workstation's microphone. Use headphones while it is on; there is no echo cancellation.
  • Clipboard. Text copied on one device can be pasted on the other.
  • Away from home. With a VPN such as Tailscale on both devices, Foldtop connects from anywhere. Connect once at home first so the app learns the workstation's VPN address.

Help

The workstation is not listed under On This Network

Check that the companion is running with foldtop-host status, that both devices are on the same Wi-Fi, and that Foldtop has Local Network access in the iPhone's Settings. You can always pair with the QR code instead.

It pairs but will not connect

This is almost always the firewall. Allow TCP port 47800 as shown above, then try again.

The picture is black or the companion will not start

Run foldtop-host doctor. The most common cause is a Wayland session; choose an Xorg session on the login screen.

The microphone is on but nothing is heard

In the workstation's sound settings, choose Foldtop Microphone as the input. The companion makes it the default while the microphone is on, but an application may have chosen another input for itself.

Remove a device or the companion

foldtop-host devices lists paired devices and foldtop-host unpair <name> removes one. To remove the companion, see the README.

Something else

Ask a question or report a problem on the issues page. Include the output of foldtop-host doctor if you can.

Security

  • The connection is encrypted (TLS). The app accepts only the certificate it saw when you paired.
  • Pairing needs the one-time code shown on the workstation.
  • A paired iPhone can see the screen and type and click as you. Pair only your own devices, and remove one with foldtop-host unpair.
  • Do not forward port 47800 from the internet. Use a VPN to connect from outside your network.
